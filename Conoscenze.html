Linguaggi
C
Funzioni e strutture dati

Definizione e utilizzo di funzioni con passaggio di parametri, ricorsione e funzioni della libreria standard. Gestione di vettori, stringhe e struct per l'organizzazione dei dati.

File e I/O

Operazioni di lettura e scrittura su file di testo, con gestione dell'apertura, chiusura e controllo degli errori.

Puntatori

Conoscenza dei puntatori e della loro aritmetica, inclusi puntatori a funzione e puntatori a struct.

C#
Programmazione console

Sviluppo di applicazioni console per imparere le basi del linguaggio. Creazione di giochi di base come: snacke, campominato.

Interfaccia grafica

Sviluppo di applicazioni WinForms con gestione di form multiple, componenti visivi come DataGridView. Creazione e controllo dinamico dei componenti. Ricreazione dei giochi sviluppati in console con interfaccia grafica, con la creazione di componenti in maniera dinamica.

Logica e strutture dati

Utilizzo di struct per la modellazione dei dati, algoritmi di ordinamento come il selection sort e implementazione di logiche di rottura di chiave per l'elaborazione di dati aggregati.

Gestione file e dati

Lettura e scrittura su file di testo tramite StreamReader e StreamWriter, con operazioni di ricerca, modifica e cancellazione tramite file di appoggio.

Bash

Conoscenza dei comandi base di Bash per la gestione di file e directory da terminale. Capacità di scrivere script con variabili, cicli e condizioni per l'automazione di operazioni ripetitive.

Sviluppo Web
HTML
Fondamenti HTML

Conoscenza della struttura di base di una pagina HTML, della sintassi dei tag, della formattazione del testo, delle liste e dei collegamenti ipertestuali. Gestione di immagini, tabelle e mappe immagine.

Form e controlli

Creazione di moduli con i principali controlli input, inclusi i nuovi type HTML5 come date, email e range, con attributi di validazione come required e placeholder.

HTML5 moderno

Utilizzo del Content Model semantico (<header>, <section>, <article>, ecc.), integrazione di contenuti multimediali nativi con <audio> e <video>, e implementazione del responsive design tramite media queries e meta tag viewport.

CSS
Selettori

Uso di selettori tag, classe e ID con piena comprensione di specificità e cascata, incluse pseudoclassi e pseudoelementi. Gestione del layout tramite Flexbox, Grid e float. Effetti visivi con transition e animation con @keyframes, trasformazioni 2D/3D con transform. Creazione di siti adattabili tramite media queries.

Framework — Bootstrap

Utilizzo di Bootstrap per la creazione rapida di interfacce responsive, sfruttando il sistema a griglia, i componenti predefiniti (navbar, card, modal, ecc.) e le utility classes per spacing, tipografia e colori. E l'utilizzo di icone personalizzate.

JavaScript
DOM e interazione con la pagina

Selezione e manipolazione degli elementi HTML tramite querySelector e getElementById. Creazione e modifica dinamica di contenuto, stili e attributi, con piena comprensione della differenza tra default state e current state del DOM.

Eventi e controlli

Gestione di eventi di tastiera e mouse, controlli di form come textbox, radiobutton e listbox. Utilizzo di addEventListener, dell'oggetto event e di preventDefault().

Strutture dati e oggetti

Utilizzo degli oggetti Math, window e dei timer setInterval e setTimeout. Persistenza lato client con localStorage.

Circuiti
Arduino

Esperienza nella gestione di circuiti tramite arduino utilizzando input e outuput sia tramite pin che tramite monitor seriale e per far comunicare più micropocessori tra loro. Utilizzando anche perfiferiche esterne come display LCD.

Tinkercad
Simulazione e progettazione circuiti

Utilizzo di Tinkercad per simulare e progettare circuiti elettronici prima della realizzazione fisica in laboratorio, riducendo errori e ottimizzando il design. Stesura e test del codice Arduino direttamente nell'ambiente virtuale prima del caricamento su scheda fisica.

Segnali e misurazioni

Generazione di segnali PWM tramite duty cycle e analisi dei segnali prodotti mediante oscilloscopio virtuale, con lettura e interpretazione delle forme d'onda ottenute.

Ciricuiti
Porte logiche

So creare e progettare circuiti tramite porte logiche tramite Tabelle della verità e mappe di Karnaught per ottimizzare l'utilizzo di integrati.

Integrati

Capacità nell'utilizzare filp-flop JK, timer 555, decoder. Utilizzati in diversi cirucuiti come contatori e circuiti di memoria.

Integrati

Capacità nell'utilizzare filp-flop JK, timer 555, decoder. Utilizzati in diversi cirucuiti come contatori e circuiti di memoria, sommatori.

Oscilloscopio

Utilizzo dell'oscilloscopio per misurare segnali elettrici, interpretare forme d'onda. Decodificare trasmissioni seriali e misurare frequenze e duty cycle di segnali digitali. Utilizzo di sonde per misurare segnali in circuiti reali.

IDE
Visual Studio Code

Utilizzo di Visual Studio Code come ambiente di sviluppo principale per progetti eterogenei, dal Web (HTML, CSS, JavaScript) ai linguaggi di sistema come C e Bash. Configurazione di estensioni, integrazione con Git per il controllo di versione e utilizzo del terminale integrato per operazioni di debug.

Visual Studio 2022

Sviluppo soluzioni in C#, spaziando dalle applicazioni console ai progetti con interfaccia grafica. Gestisco con sicurezza l'intero ciclo di debug e la manipolazione dei file.

Git
Git

Gestione del ciclo di vita di un progetto tramite Git, dalla creazione e gestione dei branch alla risoluzione dei conflitti. Operatività sia da terminale che tramite interfacce grafiche come GitHub Desktop e Visual Studio Code. Esperienza nei flussi di lavoro collaborativi tramite pull request, code review e merge.

GitHub Workspace

Utilizzo di GitHub come strumento di collaborazione per la gestione del ciclo di vita del codice, dalla revisione tramite pull request alla pubblicazione di progetti su GitHub Pages. Esperienza nella configurazione di GitHub Classroom e organizzazioni per il lavoro di squadra.
